# Monitor Chile — resultados y criterios

- [ ] **Arquitectura SPA y contratos desacoplados.** Crear una SPA con React 18+, TypeScript y Vite. Los componentes TSX no deben contener cifras macroeconómicas ni textos de contenido económico hardcodeados: leer toda la información únicamente mediante `src/services/dataService.ts` desde `/public/mock-data/*.json`. Crear contratos tipados para `app_metadata.json`, `timeline_events.json`, `summary_cards.json` y `charts_series.json`, junto a `src/types/monitor.types.ts`. La maqueta debe indicar expresamente que sus ejemplos son datos demostrativos no verificados, no una conexión oficial en tiempo real.

- [ ] **Motores Python aislados para fuentes chilenas.** Crear en la raíz `data-engines/schema_validator.py` y las carpetas `bcch_engine/`, `ine_engine/`, `dipres_engine/` y `mds_nowcast_engine/`. Cada carpeta debe incluir `engine_template.py`, un README con el esquema JSON exacto a producir y el archivo extractor nominal indicado por el PRD (`bcch_extractor.py`, `ine_extractor.py`, `dipres_extractor.py`, `poverty_extractor.py`). Documentar escritura de los JSON de `/public/mock-data/`; mantener estos motores como plantillas sin credenciales ni extracción real. Cubrir BCCh (Imacec, TPM, dólar, UF, balanza), INE (IPC, desocupación ENE, IAC, IPI), DIPRES (frente fiscal y balance estructural), y MDS/CASEN (pobreza/Canasta Básica).

- [ ] **Navegación, búsqueda y filtros compartibles.** Crear cabecera Monitor Chile con buscador de indicadores, badge clicable de series demoradas, navegación Monitor/Datos/Contacto, selector EN y toggle de modo oscuro. Implementar filtros de categoría Visión general, Actividad, Precios, Dólar y UF, Comercio exterior, Tasas (TPM), Frente fiscal, Empleo y Pobreza; filtro Mensual desest. o Interanual; y períodos Último dato, Último mes completo, En lo que va del año, Últimos 12 meses y Personalizado. Sincronizar filtros con query params y proporcionar «Compartir esta vista» para copiar la URL seleccionada. Crear modal/popover con el detalle de las series demoradas.

- [ ] **Línea de tiempo e indicadores principales.** Mostrar «Últimos datos y lo que viene» en una línea vertical con datos publicados y eventos próximos, fecha, indicador, período, valor/fuente o institución. Crear cuatro tarjetas para Actividad, Inflación, Empleo y Pobreza, cada una con título, nombre y tipo de variación del indicador principal, KPI destacado, diagnóstico/contexto, tres subindicadores, período, semántica de color y enlaces de fuente.

- [ ] **Gráficos, pie institucional y presentación adaptable.** Crear cuatro gráficos históricos con Recharts, tooltips minimalistas, metadatos y pie con fuente/período/unidad; usar ComposedChart, ejes dobles, barras apiladas y líneas según contrato de series. Crear pie institucional de tres columnas y créditos. Aplicar el fondo cálido `#F5F4F0`/`#F7F7F5`, fondo oscuro `#141413`, tarjetas `#FFFFFF`/`#1E1E1C`, bordes discretos, radios redondeados, sans-serif limpia, cifras tabulares y colores semánticos verde/rosa-rojo/neutro. Hacer responsivas grillas, filtros y tarjetas.
